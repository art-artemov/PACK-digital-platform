# DP.M.407 — Оценка объёма долга: сплошной поиск с двумя отсевами

## Определение

Объём накопленного долга (локализационного, конфигурационного, любого выразимого машинным признаком) измеряется сплошным поиском по признаку с последующими двумя отсевами, а не выборочным осмотром мест, где симптом заметили глазами.

## Когда применять

Постановка РП звучит как «нашли N случаев глазами, но неизвестно, сколько ещё» — то есть оценка объёма построена на симптомах, а не на измерении.

## Алгоритм

1. **Сплошной поиск по машинному признаку.** Признак должен быть механически проверяем: кириллица в шаблонах, литерал-константа, маркер-комментарий. Результат — верхняя граница.
2. **Отсев по классу совпадения.** Убрать совпадения, которые по своей природе не являются долгом: шаблонные комментарии-шапки, резервные копии (`.bak`), закомментированный код.
3. **Отсев по достижимости.** Убрать файлы, не подключённые в карте документа / роутинге / сборке — код, до которого исполнение не доходит, долгом не является.
4. **Остаток — и есть объём.** Это нижняя граница, полученная измерением, а не оценкой.

**Случай WP-93:** 900 строк в 118 файлах → 62 после отсева шаблонных шапок → 10 в 8 файлах после отсева недостижимых → 4 живые подписи. Две из четырёх глаз не заметил.

## Почему выборка по симптомам даёт двойную ошибку

Осмотр глазами ошибается в обе стороны одновременно: пропускает существующие вхождения (их не видно на просмотренных страницах) и завышает страх перед неизвестным остатком («у других разделов всплывёт больше»). Сплошной поиск снимает обе ошибки за то же время — здесь пятнадцать минут.

## Побочный продукт

Отсев по достижимости сам по себе — инвентарь мёртвых файлов. Его не следует смешивать с текущим РП: список фиксируется, решение об удалении принимает пилот отдельно.

## Ограничение применимости

Метод требует машинного признака долга. Если долг выражается только смыслом (неточная формулировка, устаревшая логика без синтаксического следа) — сплошной поиск неприменим, шаг 1 не строится. Отсев по достижимости корректен только при существующей карте подключений: если карты нет, «не найдено ссылок» не равно «не подключено».
