# DP.M.399 — Диагностика директории по mtime и содержимому до удаления

## Определение

Перед удалением ничейной директории установить создателя по timestamp и содержимому, выяснить куда процесс будет писать после удаления.

## IPO

- **Вход:** директория с неизвестным назначением (пустая или с артефактами)
- **Процесс:** (1) `stat <dir>` → mtime; (2) сравнить mtime с timestamp-именами файлов внутри; (3) совпадение → один процесс; (4) `grep -r "<dir>" .claude/skills/` → какой скилл/скрипт пишет сюда; (5) решение: удалять / оставить / добавить README
- **Выход:** диагноз «мусор» ИЛИ «штатный приёмник артефактов»

## Критерий

«Удалишь — куда пойдут файлы следующего запуска?» Ответ на этот вопрос — условие удаления.

## Контекст

Директория `IWE/scripts/` создана 15 июля в 17:59 — одновременно с `iwe-audit-20260715-175936.log` внутри. Первоначальный план «удалить лишнюю папку» отменён — папка является штатным приёмником логов скилла `/audit-installation`. Удаление перенаправило бы runtime-артефакты в чистое рабочее дерево соседнего репо.
