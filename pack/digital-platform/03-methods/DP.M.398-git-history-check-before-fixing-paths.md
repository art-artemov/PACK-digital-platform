# DP.M.398 — Проверка git-истории до починки путей

## Определение

При обнаружении «сломанного пути» (файл/скрипт не найден) — перед правкой пути выполнить `git log --all -- <path>` по целевому репо. Если файл никогда не существовал в git-истории → это дефект поставки, а не сломанный путь.

## IPO

- **Вход:** ошибка «файл не найден» по задокументированному пути
- **Процесс:** `git log --all -- <path>` → если пусто → файл никогда не существовал; если есть коммиты → файл удалён или перемещён
- **Выход:** диагноз «сломанный путь» ИЛИ «непоставленный артефакт» с соответствующим маршрутом фикса

## Таблица различения

| Симптом | `git log` результат | Причина | Маршрут фикса |
|---------|--------------------|---------|--------------|
| Файл не найден | Есть коммиты | Путь изменился | Правка ссылки |
| Файл не найден | Пусто (нет истории) | Артефакт не поставлен | Bug-report владельцу платформы |

## Когда применять

- Скилл/скрипт вызывает файл, которого нет
- CLAUDE.md / SKILL.md содержит ссылку на несуществующий артефакт
- Функция заявлена в документации, но не работает

## Контекст

Скилл вызывал `session-guard.sh` по жёсткому пути. Первая гипотеза: «путь неправильный, надо поправить на `$IWE_SCRIPTS`». `git log --all` показал: скрипт никогда не существовал — фича задекларирована в SKILL.md, но не реализована. Правка пути лишь замаскировала бы дефект поставки.
