# Строка темпа

## 1. Определение

**Строка темпа** — одна строка в утреннем плане дня, отвечающая на вопрос «можно ли сегодня
наваливать». Собирается из ночных показателей часов (сон, пульс покоя, вариабельность пульса
во сне) сравнением с личной нормой пилота за последние три недели.

Строка — не оценка здоровья и не диагноз. Это рабочее суждение о допустимой нагрузке,
которое пилот волен отвергнуть, увидев основание.

## 2. Назначение

Без неё предохранитель темпа работает на ощущениях: оценка состояния ставится на глаз раз
в две недели, а о перегрузе пилот узнаёт задним числом, по сорванным дням и переносам.
Строка ставит наблюдаемый признак в ту точку, где решение о темпе принимается — при сборке
плана дня, до того как день распланирован.

## 3. Структура

Строка всегда состоит из трёх частей, и ни одна не опускается.

| Часть | Что содержит | Пример |
|-------|--------------|--------|
| Вывод | одно из трёх: можно наваливать / обычный темп / поберечься | «Темп: поберечься» |
| Признаки | каждый показатель со значением и отклонением от личной нормы | «пульс покоя 62 уд, +6 уд к обычному» |
| Возраст данных | дата показателей и сколько времени прошло | «Данные за 28 августа, 15 ч назад» |

### 3.1. Отказы

Отказ — полноценный ответ, а не пустое место. Молчаливая подстановка вчерашних значений
запрещена: предохранитель, который врёт в сторону «наваливай», хуже отсутствующего.

| Причина | Что говорит строка |
|---------|-------------------|
| Выгрузок ещё не было | «вывода нет — выгрузок ещё не было» |
| Данные старше 36 часов | «вывода нет — последние данные за <дата>, выгрузка не приходила больше суток» |
| Ни одного показателя за день | «вывода нет — за <дата> не приехал ни один показатель» |
| Личной нормы ещё нет (меньше 7 дней) | «вывода нет — норма ещё копится» плюс сегодняшние значения |

### 3.2. Оговорки

| Условие | Пометка в строке |
|---------|------------------|
| Данные не за прошедшую ночь | «Это позапрошлая ночь: прошедшую телефон ещё не выгрузил» |
| Часть показателей не приехала | «Не приехало: <показатели>» |
| Вывод построен на одном признаке | «Вывод на одном признаке — доверять осторожно» |

## 4. Как считается вывод

Каждый показатель сравнивается с медианой за последние три недели. Отклонение считается
значимым от порога: сон — полчаса, пульс покоя — три удара, вариабельность — пять
миллисекунд. Значимое отклонение в хорошую сторону даёт плюс, в плохую — минус, сумма
определяет вывод.

Пороги и окно нормы — предмет пересмотра по мере накопления данных: они выбраны из практики,
а не из наблюдений за этим конкретным пилотом.

## 5. Где живёт

Сами показатели остаются в приватном хранилище самомониторинга и в план дня не попадают.
В план дня уходит только вывод и названия признаков со значениями.

## 6. Ограничения

- **Время выгрузки не управляется.** Телефон выкладывает данные, когда сойдутся условия
  (зарядка, простой, сеть), а не в заданный час. Поэтому строка иногда говорит о прошедшей
  ночи, а иногда о позапрошлой, и обязана это называть.
- **Собственная оценка готовности часов недоступна.** Она остаётся внутри приложения
  производителя, поэтому вывод строится из сырых показателей.
- **Глубина истории у показателей разная.** Сон есть за сотни дней, пульс покоя
  и вариабельность — только с тех пор, как часы начали их отдавать.
